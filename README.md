# Jetpunk Quiz Solver

This is a simple Python script that solves quizzes on [Jetpunk](https://www.jetpunk.com/).

## Installation

```bash
pip install keyboard pyautogui
```

or

```bash
pip install -r requirements.txt
```

## Usage

1. Add all the options into input.txt
2. Run the Script
3. Press F2 when in the input field

## Examples

- see example folder

### Europe/World Solver

- Takes 1 second
- Copy from example folder into input.txt
- Run the script
- Press F2

## How to get the input

1. Choose the quiz
2. Click on "Give Up"
3. Scroll Down
4. Copy the Solution
5. Paste it into input.txt
6. Remove unnecessary information (like the Continents in the world quiz)
